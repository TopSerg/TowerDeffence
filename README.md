# TowerDeffence — этап 3: рабочие, ресурсы и строительство

Java/Swing-прототип Tower Defense с динамической навигацией врагов, волнами, стенами, тремя башнями, логистикой, модульными улучшениями и физической экономикой.

## Структура проекта

- `src/main/java/towerdefence/app` — точка входа приложения;
- `src/main/java/towerdefence/game` — состояние и игровой цикл;
- `src/main/java/towerdefence/world` — карта, клетки и поиск пути;
- `src/main/java/towerdefence/building` — здания и строительство;
- `src/main/java/towerdefence/combat` — враги, волны, башни и оружие;
- `src/main/java/towerdefence/unit` — юниты и рабочие;
- `src/main/java/towerdefence/resource` — ресурсы и инвентари;
- `src/main/java/towerdefence/ui` — Swing-интерфейс;
- `src/test/java` — тесты;
- `docs` — документация и [план разработки](docs/TODO.md);
- `.idea` — настройки IntelliJ IDEA;
- `out` — результаты компиляции (не добавляются в Git).

## Что изменилось в этапе 3

### Полноценные ресурсы

На карте размещаются два добываемых сырьевых ресурса:

- `METAL` — металл;
- `COAL` — уголь.

Каждое месторождение хранит конкретный остаток. Количество отображается прямо на карте. После извлечения последней единицы месторождение удаляется с клетки.

Металлолом (`SCRAP`) сохранён как особый боевой ресурс за уничтожение роботов и используется для модулей башен. Сами здания теперь строятся из металла и угля.

### Безопасный Inventory

`Inventory` поддерживает:

- полное добавление и удаление без частичного изменения при ошибке;
- частичное добавление до свободной вместимости;
- частичное удаление до доступного количества;
- безопасный перенос между инвентарями;
- общий объём, свободное место, проверку пустоты и заполнения.

### Инвентарь рабочего

Стартовый рабочий находится в `(5,5)` и имеет собственный инвентарь на `24` единицы. В интерфейсе показываются:

- текущее состояние рабочего;
- заполнение инвентаря;
- переносимый металл и уголь;
- активная стройка.

### Автоматическая добыча

Если в очереди нет строительных задач, рабочий:

1. выбирает ближайшее доступное месторождение металла или угля;
2. едет к нему;
3. добывает ресурс по таймеру;
4. заполняет ограниченный инвентарь;
5. возвращается к главному зданию;
6. выгружает ресурсы в общий склад;
7. повторяет цикл.

Состояния добычи:

```text
IDLE → MOVING_TO_RESOURCE → MINING → RETURNING → UNLOADING
```

Можно выбрать рабочего кликом, а затем кликнуть по конкретному месторождению, чтобы назначить его приоритетной целью.

### Строительство рабочим

При размещении постройки теперь создаётся не готовое здание, а `ConstructionSite` — чертёж.

- стоимость резервируется на складе;
- ресурсы не телепортируются на стройку;
- рабочий забирает материалы с базы порциями до 24 единиц;
- для дорогих зданий выполняет несколько рейсов;
- доставляет материалы в чертёж;
- после полной доставки начинает сборку;
- прогресс отображается полосой на чертеже;
- после завершения чертёж заменяется настоящим зданием.

Дополнительные состояния рабочего:

```text
MOVING_TO_STORAGE → LOADING_CONSTRUCTION → MOVING_TO_BUILD_SITE
→ DELIVERING → BUILDING
```

Несколько размещённых чертежей образуют план работ. Один рабочий выполняет их по порядку постановки. Строительство имеет приоритет над автономной добычей.

Удаление чертежа освобождает ещё не забранный резерв и возвращает уже доставленные материалы. Если чертёж уничтожен противником, доставленные материалы теряются.

### Стоимость зданий

- пулемётная башня: 42 металла + 5 угля;
- снайперская башня: 70 металла + 12 угля;
- замедляющая башня: 55 металла + 10 угля;
- стена: 8 металла + 1 уголь;
- конвейер: 2 металла;
- бур: 28 металла + 4 угля.

Стабилизаторы и охлаждение продолжают использовать металл и металлолом.

### Панель запасов

Правая панель показывает:

- металл, уголь и металлолом;
- свободный остаток после резервирования чертежей;
- заполнение склада;
- число работ в очереди;
- состояние выбранного рабочего или здания.

## Стартовая конфигурация

- карта: `20 × 20`;
- рабочий: `(5,5)`;
- главное здание: `(6,5)`;
- точка появления врагов: `(2,3)`;
- база: `300 HP`;
- патроны: `500`;
- металл: `220`;
- уголь: `80`;
- металлолом: `15`;
- подготовка перед первой волной: `45 секунд`.

## Управление

- `B` — открыть панель строительства;
- ЛКМ по карточке — выбрать постройку;
- ЛКМ по карте — разместить чертёж;
- `R` — повернуть конвейер;
- `Esc` или ПКМ — отменить строительство;
- `Delete` / `Backspace` — снести выбранное здание или отменить чертёж;
- ЛКМ по рабочему, затем по залежи — назначить месторождение;
- ЛКМ по башне — модули и продажа;
- кнопка «Настроить время» на плашке таймера — изменить задержку до волн (1–3600 секунд);
- `N` — тестовый противник;
- `Enter` — новая игра после победы или поражения.

## Сборка

```bash
mkdir out
javac -encoding UTF-8 -d out $(find src/main/java -name "*.java")
java -cp out towerdefence.app.Main
```

```bash
java -Djava.awt.headless=true -cp out towerdefence.Stage3FeatureTest

```

`Stage3FeatureTest` проверяет ограничение инвентаря, автономную добычу, резервирование ресурсов, появление чертежей, физическую доставку и последовательное выполнение двух строительных задач.
