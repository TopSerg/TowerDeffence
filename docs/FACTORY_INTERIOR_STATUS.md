# Статус фабричной системы — 14.08.2026

## ✅ Выполнено: внутренняя геометрия Workshop

Безопасный инкремент «внутренняя геометрия Workshop» завершён:

- Workshop имеет отдельную строительную сетку 9×9;
- соблюдается пространственное правило `1 внешняя клетка = 3×3 внутренних клеток`;
- каждый из 12 возможных внешних INPUT/OUTPUT PORT 1×1 получает свои три конкретные граничные клетки Gateway;
- Gateway резервирует эти клетки: внутренний конвейер поверх него поставить нельзя;
- если новый порт появляется поверх временной внутренней раскладки, его Gateway освобождает свои три клетки;
- внутри Workshop можно прокладывать внутренние конвейеры, выбирать их, поворачивать `R` и удалять `Delete/Backspace`;
- `B` внутри Workshop включает/выключает режим прокладки внутренних конвейеров;
- внешний игровой цикл продолжает обновляться при просмотре интерьера;
- добавлен `WorkshopInteriorFeatureTest` для сетки, всех 12 положений портов, Gateway, внутренних конвейеров и lifecycle удаления Workshop/портов.

## ⏳ Намеренно не входит в этот шаг

Следующим отдельным проверяемым шагом остаются:

- реальные предметы на внутренних конвейерах;
- передача предметов через INPUT/OUTPUT Gateway;
- сохранение общего throughput при переходе `1 внешняя линия → 3 внутренние линии`;
- сортировка METAL / COAL / SCRAP;
- Ammo Press и рецепты;
- физический цикл внутреннего строительства через Васю и строительного робота.

То есть геометрия и редактирование интерьера готовы; транспорт и производство пока не считаются реализованными.
