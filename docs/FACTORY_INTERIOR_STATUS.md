# Статус фабричной системы — 14.08.2026

## ✅ Выполнено: внутренняя геометрия Workshop

- Workshop имеет отдельную строительную сетку 9×9;
- соблюдается правило `1 внешняя клетка = 3×3 внутренних клеток`;
- каждый внешний INPUT/OUTPUT PORT получает свои три граничные клетки Gateway;
- Gateway резервирует клетки периметра;
- внутри Workshop можно ставить, выбирать, поворачивать и удалять внутренние конвейеры.

## ✅ Выполнено: первый реальный pass-through ресурсов

Реализована минимальная физическая цепочка без обработки ресурса:

`Drill → внешний Conveyor → INPUT PORT → Gateway → внутренние Conveyor → OUTPUT PORT → внешний Conveyor → Storage`.

Зафиксированные правила:

- INPUT/OUTPUT Port имеют собственный буфер;
- предмет существует внутри Workshop как отдельная единица с конкретной внутренней клеткой;
- за один внутренний логистический такт предмет проходит максимум одну клетку;
- INPUT Gateway распределяет последовательные предметы по трём внутренним линиям по кругу, если линии построены;
- один внешний порт принимает или отдаёт максимум одну единицу за логистический такт;
- поэтому три внутренние линии не умножают внешний throughput: суммарный поток остаётся ограничен внешним портом;
- если построена только одна из трёх внутренних линий, Gateway использует её и не требует заполнения всех трёх;
- внешние конвейеры и Drill подсвечиваются активными, когда маршрут через Workshop действительно подключён;
- на внешнем Factory Port отображается размер его Gateway-буфера.

Добавлен `WorkshopThroughputTest`, который проверяет лимит одной внешней передачи, round-robin трёх линий и полный маршрут от Drill до главного склада.

## ⏳ Намеренно не входит в этот шаг

Следующими отдельными проверяемыми шагами остаются:

- сортировка смешанного потока METAL / COAL / SCRAP;
- настраиваемые фильтры, priority и overflow;
- Ammo Press и рецепты;
- производство боеприпасов и модулей;
- физическое внутреннее строительство через Васю и строительного робота.

То есть Workshop уже умеет физически пропускать сырьё насквозь, но пока ничего с ним не производит и не сортирует.
